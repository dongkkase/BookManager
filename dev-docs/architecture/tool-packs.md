# 도구팩과 성능 정책

## 분류

- 기본 도구: 텍본 정리와 일반 이미지 크기 변경처럼 기존 런타임으로 실행할 수 있는 기능
- 지연 로딩 도구: PDF 처리처럼 추가 JavaScript 모듈이 필요하지만 기본 배포에 포함할 수 있는 기능
- 선택 설치 도구팩: AI 모델, OCR 언어팩과 대형 네이티브 실행 파일이 필요한 기능

## 기본 앱 정책

- 도구 카탈로그는 작은 레지스트리 정보만 읽습니다.
- 도구 UI와 작업 모듈은 사용자가 도구를 열거나 실행할 때 동적으로 불러옵니다.
- AI 모델 세션과 대형 네이티브 모듈을 앱 시작 과정에서 초기화하지 않습니다.
- 준비 중인 도구는 모델, 실행 파일과 실행 모듈을 포함하지 않습니다.

## 선택 설치 정책

- 다운로드 전에 예상 용량과 지원 플랫폼을 표시합니다.
- 운영체제와 CPU 아키텍처에 맞는 파일만 다운로드합니다.
- 임시 경로에 받은 뒤 체크섬을 검증하고 설치 경로로 이동합니다.
- 도구팩 버전은 앱 버전과 별도로 관리합니다.
- 환경 설정에서 설치된 도구팩의 용량을 확인하고 삭제할 수 있어야 합니다.
- 사용하지 않는 이전 버전은 안전하게 정리합니다.

## 패키징 정책

- AI 모델과 대형 실행 파일을 `src` 아래에 저장하지 않습니다.
- `extraResources`에 포함되는 디렉터리에 대형 자산을 추가하기 전에 배포 범위를 확인합니다.
- 플랫폼별 바이너리를 모든 배포본에 함께 넣지 않습니다.
- 신규 의존성을 추가하기 전에 기존 `pica`, `pdfjs-dist`, `onnxruntime-node`를 재사용할 수 있는지 검토합니다.

## 실행 성능

- 대형 텍스트는 청크 또는 스트림 단위로 처리합니다.
- 압축 파일 이미지는 한 번에 전부 메모리에 풀지 않습니다.
- CPU 집약 작업은 Worker 또는 별도 프로세스에서 실행합니다.
- AI 이미지 작업은 기본적으로 한 장씩 처리하고 장치 메모리가 충분할 때만 병렬 수를 늘립니다.
- 작업 종료 후 사용하지 않는 모델 세션과 Worker를 해제합니다.

## 확인 항목

- 빌드 결과와 설치 파일 크기
- 앱 실행부터 첫 화면 표시까지 걸린 시간
- 첫 화면 표시 후 메모리 사용량
- 도구를 처음 열 때 걸린 시간
- 작업 중 최대 메모리와 취소 응답 시간
