# 새 파일 도구 체크리스트

## 도구 정의

- 도구 ID가 기존 ID와 겹치지 않습니다.
- 카테고리, 표시 순서와 상태를 지정했습니다.
- 지원 파일 형식과 플랫폼을 정의했습니다.
- 한국어, 영어와 일본어 문구를 추가했습니다.

## 화면

- 준비 중 도구는 실행 모듈을 불러오지 않습니다.
- 사용 가능한 도구 컴포넌트는 동적으로 로드합니다.
- 파일이 없을 때 빈 상태 화면을 제공합니다.
- 지원하지 않는 파일과 이유를 표시합니다.

## 파일 처리

- Renderer에서 직접 파일을 수정하지 않습니다.
- 결과를 임시 파일에 먼저 저장합니다.
- 기본값으로 원본을 덮어쓰지 않습니다.
- 파일명 충돌 정책과 작업 취소를 지원합니다.

## 성능과 배포

- 앱 시작 시 도구 모듈과 모델을 로드하지 않습니다.
- 대형 파일을 React 상태에 여러 벌 보관하지 않습니다.
- CPU 집약 작업을 Worker 또는 별도 프로세스에서 실행합니다.
- 신규 의존성과 도구팩의 배포 용량을 확인했습니다.

## 검증

- 정책 함수 테스트를 추가했습니다.
- 정상, 오류와 취소 흐름을 확인했습니다.
- Windows와 macOS 경로를 확인했습니다.
- 변경 전후 빌드 크기와 시작 시간을 비교했습니다.
