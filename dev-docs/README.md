# BookManager 개발 문서

이 폴더는 BookManager의 구조, 기능 범위와 반복 작업 절차를 코드와 함께 관리합니다. 사람과 개발 도구가 같은 기준을 사용할 수 있도록 결정된 내용만 기록하며, 임시 대화와 개인 메모는 보관하지 않습니다.

## 문서 안내

- 파일 도구 구조: `architecture/file-tools.md`
- 선택 설치 도구팩과 성능 정책: `architecture/tool-packs.md`
- 텍본 정리기 기능 범위: `features/text-cleaner.md`
- 새 파일 도구 추가 절차: `checklists/new-tool.md`

## 관리 원칙

- 실제 동작의 최종 기준은 코드와 테스트입니다.
- 구조나 공개 인터페이스가 바뀌면 관련 문서를 같은 변경에서 갱신합니다.
- 도구 이름, 상태와 표시 순서처럼 코드로 표현되는 정보는 도구 레지스트리를 기준으로 합니다.
- API 키, 인증서, 실제 사용자 데이터와 로컬 절대 경로는 기록하지 않습니다.
- AI 모델과 대형 실행 파일은 저장하지 않고 식별자, 버전, 크기와 설치 정책만 기록합니다.
