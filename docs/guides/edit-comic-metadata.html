BOOKMANAGER · 사용 가이드

ComicInfo.xml로 만화책 메타데이터를 일괄 편집하는 방법

BookManager는 만화책 정보를 검색해 같은 시리즈에 일괄 적용하고, ZIP·CBZ·7Z 안에 ComicInfo.xml로 저장합니다. 작가·출판사 같은 공통 정보와 각 권의 제목·권수를 나눠 확인하면 여러 권을 정리하기 쉽습니다.

최종 수정 2026년 9월 21일 · Windows / macOS

이 가이드에서

  1. 파일별 저장 범위
  2. 검색부터 저장까지
  3. 시리즈 일괄 적용 예시
  4. 표지를 바꾸는 방법
  5. 저장 결과 확인

파일별 저장 범위

ComicInfo.xml은 만화책 제목, 시리즈, 작가, 출판사, 줄거리 등을 담는 정보 파일입니다. 메타데이터를 읽는 기능과 원본에 저장하는 기능은 지원 범위가 다릅니다.

만화책 메타데이터 관리 기준
파일 형식분석원본 내부 저장
ZIP, CBZ, 7Z지원ComicInfo.xml 저장 지원
RAR, CBR지원직접 저장 미지원

RAR·CBR에 정보를 저장해야 한다면 먼저 압축 파일 구조 정리에서 CBZ로 변환한 뒤 결과 파일을 추가하세요. EPUB·PDF·TXT·오디오북은 ComicInfo.xml과 다른 방식으로 저장되며, 전체 범위는 메타데이터 관리 설명서에서 확인할 수 있습니다.

저장은 실제 파일을 변경합니다. 원본을 보관하려면 작업 전에 환경 설정의 ‘원본 백업’을 켜세요. 일괄 편집에서 ‘빈 값도 덮어쓰기’를 켜면 기존 정보가 빈 값으로 지워질 수 있습니다.

검색부터 저장까지

  1. 편집할 책을 추가합니다. ‘메타데이터 관리’ 화면에 파일 또는 폴더를 추가하고, 왼쪽 목록에서 책 한 권을 선택합니다.
  2. 책 정보를 찾습니다. 통합검색 또는 개별 검색 소스를 선택하고 작품명을 검색합니다. 결과의 작품명·작가·판본이 원하는 책과 맞는지 확인합니다.
  3. 검색 결과를 가져옵니다. 올바른 결과를 편집 영역에 불러온 뒤 제목, 시리즈, 작가, 출판사, 줄거리 등을 확인하고 필요한 값을 수정합니다. 검색을 쓰지 않고 직접 입력할 수도 있습니다.
  4. 적용 대상을 정합니다. 현재 책 한 권에 적용하거나, 같은 시리즈에 공통 정보를 일괄 적용합니다. 각 권의 제목·권수·화수·페이지 수는 파일별로 확인합니다.
  5. 파일에 저장합니다. ‘저장’은 현재 책을, ‘모두 저장’은 체크된 책을 처리합니다. 일괄 적용만 한 상태와 파일 저장을 마친 상태를 구분하세요.

만화책 검색 소스에는 리디북스, 문피아, YES24, 알라딘, Google Books, AniList, Comic Vine이 있습니다. 일부 소스는 환경 설정에 API 키를 입력해야 사용할 수 있습니다.

시리즈 일괄 적용 예시

예시 만화 01권.cbz, 02권.cbz, 03권.cbz를 정리한다면 공통 정보와 권별 정보를 다음처럼 구분합니다.

같은 시리즈 세 권을 편집할 때
구분예시확인 방법
공통 정보시리즈 ‘예시 만화’, 작가, 출판사, 장르같은 시리즈인지 확인하고 일괄 적용
권별 정보01·02·03권, 각 권의 부제와 페이지 수각 파일을 선택해 개별 확인

파일명에서 제목·권수·화수를 추출하는 자동 입력도 사용할 수 있습니다. 파일명 규칙에 따라 결과가 달라지므로 저장 전에 실제 권수와 맞는지 확인하세요.

표지를 바꾸는 방법

표지 이미지는 ComicInfo.xml의 글자 정보와 별도로 다룹니다. 직접 준비한 이미지를 여러 책에 적용하려면 ‘폴더’ 탭의 표지 편집을 사용하세요.

  1. 폴더 탭에서 표지를 바꿀 파일을 선택하고 우클릭 메뉴의 ‘커버 추가 및 교체’를 엽니다.
  2. ‘커버 이미지 선택’을 누르거나 이미지 한 개를 편집 창에 끌어다 놓습니다.
  3. 기존 커버와 새 커버를 비교하고 ‘기존 커버 교체’ 등 적용 방식과 원본 백업 옵션을 확인합니다.
  4. ‘커버 저장’을 누르고 처리 결과를 확인합니다. 여러 파일을 선택했다면 같은 이미지가 적용되므로 대상 목록을 먼저 확인하세요.

표지 편집에서 RAR·CBR은 원본 내부에 직접 저장하지 않고 별도 CBZ를 만듭니다. 형식별 차이는 표지 편집 설명서를 참고하세요.

저장 결과 확인

  • 저장한 파일을 다시 선택해 제목, 시리즈와 권수가 맞는지 확인합니다.
  • ‘모두 저장’ 결과에서 실패하거나 저장하지 못한 파일이 있는지 확인합니다.
  • Kavita, Komga, YACReader, Panels 등 ComicInfo.xml 지원 앱에서도 활용할 수 있습니다. 표시되는 항목은 각 앱의 지원 범위에 따라 다릅니다.
  • NAS의 파일을 수정할 때는 해당 폴더의 쓰기 권한과 연결 상태를 확인합니다.

함께 보면 좋은 가이드

  • NAS의 책을 등록하고 모바일에서 이용하는 방법

세부 옵션과 단축키는 Wiki의 전체 사용 설명을 참고하세요.
