BOOKMANAGER · 사용 가이드

NAS의 책을 등록하고 모바일에서 이용하는 방법

컴퓨터에서 폴더로 열 수 있는 NAS를 BookManager 라이브러리로 등록하면, PC에 있는 책과 함께 탐색하고 검색할 수 있습니다. 같은 네트워크의 모바일 기기에서는 공유 서버 또는 Readive 연동으로 이용합니다.

최종 수정 2026년 9월 21일 · Windows / macOS

이 가이드에서

  1. NAS 폴더 준비

NAS 폴더 준비

먼저 Windows 탐색기나 macOS Finder에서 NAS 공유 폴더를 열어 책 파일에 접근할 수 있는지 확인합니다. NAS의 웹 관리 화면 주소가 아니라, 컴퓨터에서 접근 가능한 폴더 경로를 등록해야 합니다.

NAS 경로 예시 — 실제 공유 이름에 맞게 사용하세요
환경폴더 경로 예시
WindowsZ:\Books처럼 연결한 네트워크 드라이브의 폴더
macOS/Volumes/Books처럼 마운트한 공유 폴더

읽기와 다운로드에는 파일을 읽을 권한이 필요합니다. 압축 파일 정리나 메타데이터 저장에는 해당 NAS 폴더를 수정할 권한도 필요합니다.

라이브러리 등록

  1. NAS 연결을 확인합니다. 탐색기 또는 Finder에서 실제 책 파일을 열 수 있는지 확인합니다.
  2. 폴더를 등록합니다. BookManager 환경 설정의 라이브러리 폴더에 책이 있는 NAS 폴더를 추가합니다.
  3. 알아보기 쉬운 이름을 붙입니다. ‘NAS 만화’, ‘NAS 전자책’처럼 라이브러리 별칭과 그룹을 지정할 수 있습니다.
  4. 스캔 후 탐색합니다. 폴더 탭에서 등록한 라이브러리를 스캔하고, 표지와 책 정보가 표시되는지 확인합니다.
  5. 필요한 책을 찾습니다. 파일명·폴더명·책 정보로 검색합니다. EPUB·PDF·TXT의 본문 단어로 찾으려면 내용 검색 인덱스를 별도로 만듭니다.

본문 검색은 텍스트를 추출할 수 있는 문서가 대상입니다. OCR이 필요한 스캔 PDF와 이미지형 EPUB은 본문 검색 대상에서 제외됩니다.

공유 중에는 PC도 켜져 있어야 합니다. NAS에 책이 있어도 BookManager를 통한 공유와 전송에는 BookManager 및 해당 공유·연동 기능이 실행 중이어야 합니다. PC가 NAS 폴더에 계속 접근할 수 있는지도 확인하세요.

공유 방식 고르기

사용할 앱에 맞춰 필요한 방식만 켜세요
방식용도
OPDSOPDS 지원 앱에서 책 목록을 탐색하고 다운로드
Web웹 브라우저에서 라이브러리 탐색·검색·다운로드
WebDAVComicGlass 등 WebDAV 지원 앱에서 파일 접근
Readive 연동등록한 모바일 기기에서 라이브러리 탐색·가져오기, PC에서 선택한 파일 전송

연결한 앱마다 지원 파일 형식과 재생 기능이 다릅니다. Readive 연동은 일반 OPDS·Web·WebDAV 서버와 별도로 동작합니다.

모바일 연결 순서

OPDS·Web·WebDAV로 연결

  1. PC와 모바일 기기를 같은 Wi-Fi 또는 같은 사설 네트워크에 연결합니다.
  2. BookManager의 ‘공유 서버’ 탭에서 모바일 기기와 같은 네트워크의 서버 주소를 선택합니다.
  3. 사용할 서버의 포트를 확인합니다. WebDAV를 쓴다면 아이디와 비밀번호도 설정합니다.
  4. 해당 서버를 켜고 ‘URL 복사’로 주소를 복사합니다.
  5. OPDS·WebDAV는 지원 앱에 주소를 등록하고, Web은 브라우저에서 주소를 엽니다. WebDAV 앱에는 설정한 아이디와 비밀번호를 함께 입력합니다.

직접 NAS 주소를 조합하는 대신 BookManager에 표시된 URL을 사용하세요. HTTPS를 켠 경우 자체 서명 인증서에 대한 허용 절차가 연결 앱에서 필요할 수 있습니다.

Readive로 연결

  1. BookManager의 공유 서버 탭에서 ‘리디브 연동’의 LAN 주소를 확인하고 ‘연동 켜기’를 누릅니다.
  2. Readive의 BookManager 연결 화면에서 PC에 표시된 QR 코드를 스캔합니다.
  3. 등록이 끝나면 Readive에서 라이브러리를 탐색하거나 필요한 책을 내려받습니다.
  4. PC에서 먼저 보내려면 폴더 탭에서 파일·폴더를 선택하고 ‘리디브로 전송’을 누릅니다. 받을 기기, 저장 폴더와 대상 파일을 확인한 뒤 전송을 시작합니다.

QR 코드를 사용할 수 없다면 IP 주소와 포트를 직접 입력하고 양쪽 화면의 16자리 확인 코드가 일치하는지 확인한 뒤 승인합니다. Readive 연동은 HTTPS를 사용하며 기본 포트는 19421입니다. 자세한 등록·전송 방법은 Readive 연동 설명서에서 확인할 수 있습니다.

연결이 안 될 때

  • NAS 연결: PC에서 NAS 폴더를 열 수 있는지, 네트워크 드라이브가 연결되어 있는지 확인합니다.
  • 앱과 서버 상태: BookManager와 사용할 서버가 켜져 있는지 확인합니다. Readive는 ‘리디브 연동’ 상태를 확인합니다.
  • 네트워크 주소: PC와 모바일이 같은 네트워크인지, 복사한 URL이 현재 사용하는 LAN 주소인지 확인합니다.
  • 포트와 인증: 방화벽에서 해당 포트의 연결을 허용하는지, WebDAV 계정 정보가 맞는지 확인합니다. HTTPS 연결은 인증서 상태도 확인합니다.

이 가이드는 같은 네트워크에서 사용하는 방법을 다룹니다. 외부 인터넷 연결 설정은 포함하지 않습니다. 연결 과정의 오류는 공유 서버 탭의 로그에서도 확인할 수 있습니다.
