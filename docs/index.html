Windows/macOS desktop app for comics and ebooks

BookManager

CBZ, ZIP, EPUB, PDF 파일을 정리하고 ComicInfo.xml 메타데이터를 관리하는 데스크톱 앱입니다. Kavita, Komga, YACReader, Panels, Calibre, KOReader 같은 서버와 뷰어에 맞춰 책 파일을 관리할 수 있습니다.

만화책 파일 정리

BookManager는 만화책 압축 파일을 라이브러리와 뷰어에서 읽기 좋은 형태로 정리합니다. 압축 파일 구조 정리, 평탄화, 내부 이미지 파일명 변경, 누락 페이지 확인을 지원합니다.

CBZ/ZIP 구조 정리

여러 권이 들어 있는 압축 파일을 권 단위로 정리하고, 복잡한 폴더 구조를 읽기 쉬운 형태로 맞춥니다.

내부 파일명 변경

압축 파일 안의 이미지 파일명을 일정한 규칙으로 정리해 페이지 순서 문제를 줄입니다.

ComicInfo.xml 관리

제목, 시리즈, 권수, 작가, 출판사, 줄거리, 태그 같은 메타데이터를 ComicInfo.xml로 저장합니다.

전자책 라이브러리 관리

EPUB과 PDF도 라이브러리 단위로 스캔하고 검색할 수 있습니다. 표지, 제목, 작가, 출판사, ISBN, 언어, 설명 같은 정보를 정리해 여러 전자책 환경에서 활용할 수 있습니다.

지원 파일

  • 만화책: ZIP, CBZ, CBR, RAR, 7Z
  • 전자책: EPUB, PDF
  • ComicInfo.xml 메타데이터 저장
  • EPUB OPF 메타데이터 관리

연동하기 좋은 환경

  • Kavita, Komga, YACReader, Panels
  • Calibre, Calibre-Web, KOReader
  • Apple Books, Google Play Books
  • OPDS, Web, WebDAV 공유

메타데이터 검색

리디북스, 알라딘, Google Books, AniList, Comic Vine, Amazon 등 국내외 소스를 통해 책 정보를 검색하고 편집할 수 있습니다. 만화책과 전자책을 한 라이브러리 안에서 관리하는 사용자를 기준으로 설계했습니다.

API 및 검색 설정

  • 환경설정 > API 및 검색 설정에서 만화책과 전자책에 자주 사용하는 검색 API를 각각 선택할 수 있습니다.
  • 선택한 값은 메타데이터 관리 화면의 검색 API 드롭다운 기본값으로 반영됩니다.

지원 환경

BookManager는 Windows와 macOS에서 사용할 수 있으며, 앱 UI는 한국어, 영어, 일본어를 지원합니다.

설치

릴리즈 페이지에서 Windows 또는 macOS용 파일을 내려받아 실행합니다. 언어는 앱의 환경 설정에서 한국어, 영어, 일본어 중 선택할 수 있습니다. macOS에서 처음 실행할 때 보안 경고가 표시되면 앱의 격리 속성을 제거한 뒤 실행할 수 있습니다.

프로그램은 로컬 파일을 직접 정리하는 도구입니다. 대량 작업을 실행하기 전에는 대상 목록과 미리보기를 확인하세요.
