어디에 뒀는지 몰라도 찾기

여러 드라이브의 라이브러리를 함께 검색하고, 중복 후보와 시리즈의 빠진 권수를 확인하세요.

반복되는 정리는 한 번에

압축 구조와 페이지 이름을 일괄 정리하고, 검색한 책 정보를 같은 시리즈에 함께 적용하세요.

정리한 자리에서 바로 감상

만화와 전자책을 읽고 오디오북을 들으세요. 모바일에서 볼 책은 Readive로 전송할 수 있습니다.

필요한 작업부터 따라 해보세요

합본 나누기, 책 정보 편집, NAS 연결을 단계별로 안내합니다. 지원 형식과 작업 전후 예시를 확인하고 내 라이브러리에 적용하세요.

만화책 합본 ZIP을 권별 CBZ로 나누기

압축 파일 속 권별 폴더를 분석하고, 출력 형식과 저장 위치를 확인해 여러 권으로 정리합니다.

ComicInfo.xml 메타데이터 일괄 편집

제목·작가·출판사 정보를 검색해 같은 시리즈에 적용하고, 파일별 저장 범위와 표지 편집 방법을 알아봅니다.

NAS 책을 등록하고 모바일에서 이용하기

NAS 폴더를 라이브러리로 등록하고, OPDS·WebDAV 또는 Readive로 다른 기기에서 이용합니다.

내 서재가 달라지는 과정

라이브러리 탐색부터 파일 정리, 책 정보 편집, 읽기와 모바일 전송까지 실제 앱 화면으로 살펴보세요.

제목이 가물가물해도, 기억나는 단어로

PC, 외장하드, NAS의 폴더를 라이브러리로 등록하세요. 여러 폴더를 오가지 않고 파일명과 책 정보, 본문 속 단어로 원하는 책을 찾을 수 있습니다.

책 정보와 태그로 좁혀 찾기

등록한 라이브러리를 함께 검색하고, 작가·장르·출판사·연도 등의 조건을 조합해 원하는 책을 골라 보세요.

본문에 나온 단어로 책 찾기

내용 검색 인덱스를 만들면 EPUB, PDF, TXT의 본문 단어로 책 파일을 찾을 수 있습니다. OCR이 필요한 스캔 문서는 제외됩니다.

겹친 책과 빠진 권수 확인

파일명과 권수 정보가 비슷한 중복 후보를 비교하고, 보유한 시리즈의 권·화 번호 사이에서 빠진 번호를 확인하세요.

반복되는 파일 정리, 여러 권을 한 번에

여러 권이 한 압축 파일에 섞여 있거나 페이지 이름이 제각각이어도 괜찮습니다. 파일이나 폴더를 끌어다 놓고, 결과를 미리 확인한 뒤 일괄 정리하세요.

합본을 권·화별 파일로

한 ZIP 안에 들어 있는 여러 권의 폴더를 각각의 책 파일로 나눕니다. 저장할 이름과 위치도 실행 전에 확인할 수 있습니다.

복잡한 압축 구조 정리

여러 단계로 중첩된 폴더를 정리하고, 이미지를 한곳에 모아 뷰어에서 읽기 좋은 구조로 맞춥니다.

페이지 이름과 순서 통일

내부 이미지 이름을 같은 규칙으로 바꾸고 순서를 조정합니다. 누락된 페이지 번호 확인과 이미지 용량 줄이기도 함께 처리할 수 있습니다.

변경 전후의 파일명과 작업 대상을 미리 확인할 수 있습니다. 원본을 함께 보관하려면 작업 전에 환경 설정의 ‘원본 백업’을 켜세요.

파일명만 있던 책에, 표지와 이야기를

리디북스, Google Books, AniList, Comic Vine, Amazon 등에서 책 정보를 찾아 비교하세요. 표지, 제목, 작가, 출판사와 줄거리를 가져와 알아보기 쉬운 서재로 정리할 수 있습니다.

검색해서 채우는 책 정보

검색 결과를 편집창으로 가져와 확인한 뒤 적용하세요. 제목을 알기 어려운 책은 AI 원제 찾기로 표지에서 제목 후보를 찾을 수 있습니다.

시리즈 공통 정보 일괄 적용

작가·출판사·장르·줄거리는 같은 시리즈에 함께 적용하고, 각 권의 제목·권수·페이지 수는 파일별로 관리하세요.

파일과 함께 보관하는 정보

지원 형식에 따라 ComicInfo.xml, EPUB·PDF 메타데이터, 오디오 태그와 표지를 파일에 저장합니다. TXT의 책 정보와 표지는 앱에서 별도로 보관합니다.

검색 소스는 책 종류에 따라 다르며, 일부 검색 서비스와 AI 기능에는 별도의 API 키 설정이 필요합니다.

읽고 싶은 책은 바로 열고, 듣고 싶은 책은 재생

만화책, EPUB, PDF, TXT와 오디오북을 내장 뷰어에서 감상하세요. 책갈피와 마지막 읽은 위치를 저장해 다음에 다시 펼치기도 편합니다.

내게 맞는 독서 화면

  • 한 장·두 장 보기, 스크롤과 확대·축소
  • 테마와 페이지 전환 효과로 읽기 환경 조정
  • EPUB, PDF, TXT 안에서 내용 검색과 해당 위치로 이동
  • EPUB과 TXT의 본문을 TTS로 듣기

생활에 맞춰 듣는 오디오북

  • 재생 속도와 앞뒤 이동 간격 조절
  • 재생목록과 트랙 연속 재생
  • 다시 듣고 싶은 위치에 북마크, 잠들기 전 취침 타이머
  • 책을 정리하는 동안에도 미니 플레이어로 재생

PC에서 정리한 서재를, 내 기기에서도

책을 정리하는 곳과 읽는 기기가 달라도 자연스럽게 연결하세요. Readive로 파일을 보내거나, 사용하는 앱에서 공유 라이브러리를 열 수 있습니다.

모바일에서 읽을 책은 Readive로

  • 같은 네트워크의 Readive 기기를 등록하고 연결
  • 선택한 책을 모바일 기기에 전송
  • Readive에서 BookManager 라이브러리를 탐색하고 가져오기

사용하는 앱에서도 라이브러리 탐색

  • OPDS: 지원하는 전자책 앱에서 책 목록 탐색과 다운로드
  • Web: 웹 브라우저에서 라이브러리 탐색
  • WebDAV: 지원하는 앱에서 책 파일에 접근

공유와 전송은 같은 네트워크에서 시작하세요. 연결하는 동안 BookManager와 해당 공유·연결 서비스가 실행 중이어야 합니다.

모아 둔 파일, 익숙한 형식 그대로

만화책부터 문서와 오디오북까지 하나의 라이브러리에서 관리합니다. 지원하는 작업과 메타데이터 저장 방식은 파일 형식에 따라 다릅니다.

EPUB, PDF, TXT

MP3, M4A, M4B, FLAC, AAC, AIF/AIFF, OGA/OGG/OPUS, WAV/WAVE 등

시작하기 전에 궁금한 점

무료로 사용할 수 있나요?

BookManager는 MIT 라이선스로 공개된 무료 오픈소스 앱입니다. Windows와 macOS를 지원하며, 앱 언어는 한국어·영어·일본어 중에서 선택할 수 있습니다. 외부 API를 사용하는 검색·AI·TTS 기능은 해당 서비스의 이용 조건과 요금이 적용될 수 있습니다.

NAS의 책도 관리할 수 있나요?

컴퓨터에서 폴더로 접근할 수 있는 NAS나 외장하드를 라이브러리로 등록할 수 있습니다. 표지와 책 정보를 스캔한 뒤 다른 라이브러리와 함께 검색하세요. 파일을 열거나 정리하려면 해당 드라이브에 연결되어 있어야 합니다.

책 정보를 편집하면 원본 파일도 바뀌나요?

쓰기 지원 형식은 저장할 때 실제 파일의 메타데이터를 변경합니다. TXT는 본문을 수정하지 않고 책 정보와 표지를 앱에 별도로 저장하며, RAR/CBR의 메타데이터 직접 저장은 지원하지 않습니다. 오디오북은 AAC, AIF/AIFF, FLAC, M4A/M4B, MP3, OGA/OGG/OPUS, WAV/WAVE의 태그와 표지를 저장할 수 있고, 3GP·AMR·CAF·WEBM은 분석만 지원합니다. 원본 보관이 필요하면 작업 전에 ‘원본 백업’을 켜세요.

지금 쓰는 뷰어나 책 관리 서버와 함께 쓸 수 있나요?

파일 형식별로 외부 뷰어를 지정하거나, 정리한 파일을 다른 앱에서 열 수 있습니다. ComicInfo.xml과 EPUB·PDF 메타데이터 등은 이를 지원하는 뷰어와 서버에서 활용할 수 있습니다. 표시되는 항목은 각 앱의 지원 범위에 따라 다릅니다.

첫 번째 라이브러리부터 시작하세요

운영체제에 맞는 파일을 내려받아 압축을 풀고 실행하세요. 책이 있는 폴더를 라이브러리로 등록하면 내 서재를 둘러볼 준비가 됩니다.
