READIVE · 사용 가이드

Readive와 BookManager를 연결해 PC의 책과 읽던 위치를 가져오는 방법

PC에서 BookManager로 정리한 책을 iPhone·iPad의 Readive로 가져올 수 있습니다. 같은 네트워크에서 기기를 등록하고, 필요한 책을 내려받거나 PC에서 보내면 됩니다.

최종 수정 2026년 9월 21일 · iPhone / iPad

이 가이드에서

  1. 연결 전 준비
  2. QR 코드로 처음 연결
  3. 책 가져오기와 받기
  4. 읽던 위치 이어가기
  5. 연결이 안 될 때

연결 전 준비

  • PC에서 BookManager를 실행하고, iPhone·iPad에서 Readive를 실행합니다.
  • PC와 모바일 기기를 같은 Wi-Fi 또는 같은 사설 네트워크에 연결합니다.
  • Readive에서 탐색할 폴더를 BookManager의 라이브러리로 먼저 등록합니다.
  • NAS나 외장 드라이브의 책이라면 PC에서 해당 폴더에 접근할 수 있는지 확인합니다.

‘리디브 연동’을 켜면 됩니다. Readive 연동은 일반 OPDS·Web·WebDAV 서버와 별도로 동작하므로, 연동을 위해 일반 공유 서버를 먼저 켤 필요는 없습니다.

QR 코드로 처음 연결

  1. BookManager에서 공유 서버 탭을 엽니다.
  2. 리디브 연동에서 모바일 기기와 같은 네트워크의 LAN 주소를 선택합니다.
  3. 연동 켜기를 눌러 QR 코드를 표시합니다.
  4. Readive의 BookManager 연결 화면에서 PC의 QR 코드를 스캔합니다.
  5. BookManager의 등록된 기기 목록에 iPhone·iPad가 표시되는지 확인합니다.

기기는 처음 한 번만 등록하면 됩니다. 연동을 꺼도 등록한 기기 정보는 유지되지만, 다시 책을 탐색하거나 전송할 때는 연동을 켜야 합니다.

QR 코드를 사용할 수 없다면

  1. Readive에 BookManager 화면의 IP 주소와 포트를 직접 입력합니다.
  2. Readive와 BookManager 양쪽에 표시된 16자리 확인 코드를 비교합니다.
  3. 16자리가 모두 같을 때 BookManager에서 승인합니다. 요청하지 않은 기기이거나 코드가 다르면 거절합니다.

책 가져오기와 받기

Readive에서 책을 골라 가져오기

  1. 연결된 BookManager의 라이브러리 목록을 엽니다.
  2. 원하는 라이브러리를 선택하고 책이 있는 하위 폴더로 이동합니다.
  3. 읽을 파일을 열거나, 기기의 보관함으로 다운로드합니다.
  4. 다운로드 완료 후 보관함에서 책이 열리는지 확인합니다.

현재 PC에서 접근할 수 있는 등록 라이브러리가 표시됩니다. NAS나 외장 드라이브의 연결이 끊겼다면 다시 연결한 뒤 확인하세요.

PC에서 Readive로 보내기

  1. BookManager의 폴더 탭에서 보낼 라이브러리·폴더·파일을 선택합니다.
  2. 우클릭 메뉴에서 리디브로 전송을 선택합니다.
  3. 받을 기기와 Readive 보관함의 저장 폴더를 선택합니다.
  4. 파일 목록에서 불필요한 항목을 제외하고, 파일 수와 전체 용량을 확인합니다.
  5. 전송 시작을 누른 뒤 Readive에서 수신 요청을 확인해 받습니다.

PC의 책은 복사되며 원본이 삭제되거나 이동되지 않습니다. TXT에 BookManager에서 저장한 책 정보나 사용자 표지가 있다면 함께 전송됩니다.

전송 가능한 형식과 대량 전송 한도는 Readive 연동 전체 설명서에서 확인할 수 있습니다. 현재 AIF·AIFF 오디오 파일과 심볼릭 링크는 Readive 전송 대상에 포함되지 않습니다.

읽던 위치 이어가기

연동으로 전송하거나 다운로드한 책은 BookManager와 Readive 사이에서 읽은 위치와 읽기 상태를 주고받습니다. 양쪽 기록이 다르면 더 최근에 변경된 기록을 기준으로 이어 읽습니다.

BookManager 연동으로 연결되는 정보
항목동작 방식
책 파일선택해서 다운로드하거나 PC에서 전송합니다.
읽은 위치·읽기 상태연동이 켜져 있고 기기가 같은 네트워크에 있을 때 주고받습니다.
북마크·하이라이트현재 BookManager와의 동기화 대상에는 포함되지 않습니다.

기기에 다운로드한 책은 PC와 연결되어 있지 않아도 Readive에서 읽을 수 있습니다. 읽던 위치를 PC와 다시 맞출 때는 같은 네트워크에서 BookManager와 Readive를 실행하고 연동을 켭니다.

Readive의 iCloud 기록 동기화는 iPhone·iPad 사이에서 사용하는 별도 기능입니다. BookManager 연동과 동기화 범위가 같지는 않습니다.

연결이 안 될 때

  • 앱 실행 상태: BookManager와 Readive가 실행 중이고 ‘리디브 연동’이 켜져 있는지 확인합니다.
  • 네트워크: 두 기기가 같은 네트워크에 있는지, 선택한 LAN 주소가 현재 사용하는 주소인지 확인합니다.
  • PC 방화벽: Readive 연동 포트의 연결을 허용하는지 확인합니다. 기본 포트는 19421입니다.
  • 책 목록: PC의 라이브러리 등록 상태와 NAS·외장 드라이브 연결 상태를 확인합니다.
  • 기기 등록: 등록이 풀렸다면 기존 기기 정보를 해제하고 QR 코드 또는 수동 등록으로 다시 연결합니다.

BookManager 없이 기기 파일이나 NAS의 책을 직접 가져오려면 책 가져오기 가이드를 참고하세요.

함께 보면 좋은 가이드

  • Readive에 기기·NAS의 책을 가져오고 오프라인으로 읽는 방법
  • Readive에서 EPUB·TXT를 읽고 TTS로 듣는 방법
